# Soundpad Music

Транслирует музыку из **YouTube, VK, Яндекс Музыки, SoundCloud** (и ещё ~1000 сайтов, которые понимает yt-dlp) **в микрофон через Soundpad**. Вставляешь ссылку или название, нажимаешь «▶ В микрофон», и трек играет в Discord, CS2, Dota и куда угодно, где выбран микрофон с Soundpad.

## Как это работает

Soundpad умеет проигрывать только файлы. Живой поток он не принимает. Поэтому:

1. Ссылка/название → трек (yt-dlp; для Яндекс Музыки берём «исполнитель — название» и ищем его на YouTube).
2. Трек скачивается и конвертируется в mp3 (с выравниванием громкости, чтобы в войсе не орало).
3. Через API удалённого управления Soundpad (`\\.\pipe\sp_remote_control`) файл добавляется в список и запускается **в микрофон** (и, по желанию, в ваши наушники).
4. Когда трек кончился, запускается следующий из очереди, а сыгранный убирается из списка Soundpad. Ваши звуки не трогаются.

Следующий трек скачивается заранее, пока играет текущий. Скачанное кэшируется, поэтому повторный запуск мгновенный.

## Что поддерживается

| Что вставили | Что происходит |
|---|---|
| Ссылка YouTube (видео, плейлист, Music) | качается напрямую |
| Просто текст: `кино группа крови` | первый результат поиска на YouTube |
| Яндекс Музыка: трек / альбом / плейлист `users/.../playlists/N` | название берётся из Яндекса, звук с YouTube (без подписки Яндекс отдаёт только 30-секундные превью) |
| VK видео / клипы | напрямую через yt-dlp |
| VK аудио | нужен вход: выберите браузер в «Cookies из браузера», где вы залогинены в VK. Если не вышло, введите название текстом |
| SoundCloud, Bandcamp, Twitch-клипы и т.д. | напрямую через yt-dlp |
| Spotify, Apple Music и прочее | берётся название со страницы и ищется на YouTube |

## Установка (Windows)

1. Установите **Soundpad** (Steam или leppsoft.com) и запустите его. В демо-версии удалённое управление может быть недоступно.
2. Установите **Python 3.9+** с python.org и при установке отметьте *Add python.exe to PATH*.
3. Скачайте этот репозиторий и запустите **`run.bat`**.
   При первом запуске он создаст `.venv` и поставит зависимости: `yt-dlp` и `imageio-ffmpeg`, где лежит готовый ffmpeg, ставить его отдельно не нужно.
   При каждом запуске yt-dlp обновляется: YouTube регулярно что-то ломает, и свежая версия это чинит.

## Использование

**Окно:** `run.bat` (или `python -m soundpad_music`).

- **▶ В микрофон**: добавить ссылку или название в очередь (Enter тоже работает). **Вставить** вставляет из буфера обмена и сразу добавляет.
- **⏯ Пауза / ⏭ Следующий / ⏹ Стоп всё**: управление очередью.
- Настройки:
  - *Играть в микрофон* / *Слышать самому*: куда выводить звук.
  - *Выравнивать громкость*: loudnorm до −16 LUFS.
  - *Убирать трек из Soundpad после проигрывания*: чтобы список Soundpad не засорялся.
  - *Cookies из браузера*: для VK и закрытого контента.
- Громкость в микрофоне регулируется ползунком в самом Soundpad.

**Консоль** (без окна):

```bat
.venv\Scripts\python -m soundpad_music "https://youtu.be/dQw4w9WgXcQ" "кино звезда по имени солнце"
.venv\Scripts\python -m soundpad_music --cookies chrome "https://vk.com/audio..."
```

Флаги: `--no-speakers` (не слышать самому), `--no-normalize`, `--keep` (не удалять из списка Soundpad), `--cookies BROWSER`.

Настройки и кэш лежат в `%APPDATA%\SoundpadMusic`. Кэш чистится кнопкой «Очистить кэш».

## Если не работает

- **«Soundpad не найден»**: Soundpad не запущен, или у вас демо-версия.
- **YouTube выдаёт ошибку**: перезапустите `run.bat`, он обновит yt-dlp.
- **VK не качает**: выберите браузер с залогиненным VK. Chrome/Edge нужно закрыть, пока читаются cookies (это ограничение браузера). Либо введите название трека текстом.
- **Трек слишком тихий или громкий**: ползунок громкости в Soundpad, или выключите «Выравнивать громкость».

## Разработка

```bash
pip install -r requirements.txt
python -m unittest discover -s tests
```

- `soundpad_music/soundpad.py`: клиент Soundpad (named pipe, WinAPI через ctypes).
- `soundpad_music/sources.py`: разбор ссылок, Яндекс Музыка, скачивание и конвертация.
- `soundpad_music/player.py`: очередь, предзагрузка, слежение за воспроизведением.
- `soundpad_music/gui.py`: окно на tkinter. `__main__.py`: точка входа и консольный режим.
