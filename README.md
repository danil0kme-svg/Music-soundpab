# 🎵 Soundpad Music

Программа, чтобы **включать музыку в микрофон** через Soundpad: в Discord, CS2, Dota, Telegram и куда угодно.

Вставляешь ссылку из **YouTube, VK, Яндекс Музыки, SoundCloud** (или просто пишешь название песни), нажимаешь кнопку, и все в войсе слышат музыку.

---

## 📦 Что нужно установить (один раз)

### 1. Soundpad
Купить в [Steam](https://store.steampowered.com/app/629520/Soundpad/) или на [leppsoft.com](https://www.leppsoft.com/soundpad/).
> ⚠️ Нужна **полная** версия. В демо-версии программа может не работать.

### 2. Сама программа
**[⬇️ Скачать SoundpadMusic.exe](https://github.com/danil0kme-svg/Music-soundpab/releases/latest/download/SoundpadMusic.exe)**

Это один файл, Python и прочее уже внутри. Положи его куда угодно, например на рабочий стол.

> Windows может показать синее окно «Windows защитила ваш компьютер», потому что у программы нет платной подписи.
> Нажми **«Подробнее» → «Выполнить в любом случае»**. Это нужно сделать один раз.

## ▶️ Как пользоваться

1. **Запусти Soundpad.**
2. Запусти **`SoundpadMusic.exe`**. Первый запуск может занять секунд 5–10.
3. Вставь ссылку или напиши название песни и нажми **▶ В микрофон** (или Enter).
4. Готово, музыка играет в микрофон 🎉

Можно накидать сразу много треков: они встанут в очередь и будут играть по порядку.

### Кнопки

| Кнопка | Что делает |
|---|---|
| **▶ В микрофон** | Добавить трек в очередь |
| **Вставить** | Вставить ссылку из буфера обмена и сразу добавить |
| **⏯ Пауза** | Пауза / продолжить |
| **⏭ Следующий** | Пропустить трек |
| **⏹ Стоп всё** | Остановить и очистить очередь |

### Настройки (внизу окна)

- **Играть в микрофон**: чтобы тебя слышали другие.
- **Слышать самому**: чтобы музыка играла и у тебя в наушниках.
- **Выравнивать громкость**: чтобы все песни были примерно одинаково громкими и никого не оглушали.
- **Убирать трек из Soundpad после проигрывания**: чтобы список звуков в Soundpad не забивался музыкой. Твои звуки программа не трогает.
- **Cookies из браузера**: нужно для музыки из VK (см. ниже).

🔊 **Громкость в микрофоне** регулируется ползунком громкости в самом Soundpad.

## 🔗 Что можно вставлять

| Что | Работает? |
|---|---|
| Название песни, например `кино группа крови` | ✅ ищет на YouTube |
| Ссылка на YouTube (видео или плейлист) | ✅ |
| Яндекс Музыка: трек, альбом, плейлист | ✅ название берётся из Яндекса, а звук с YouTube |
| VK видео / клипы | ✅ |
| VK музыка | ⚠️ нужен вход в VK, см. ниже |
| SoundCloud | ✅ |
| Spotify, Apple Music | ✅ ищет такую же песню на YouTube |

### Как включить музыку из VK
1. Зайди в VK в своём браузере (Chrome, Edge, Firefox…).
2. В программе в **«Cookies из браузера»** выбери этот браузер.
3. **Закрой браузер** (Chrome и Edge не дают читать cookies, пока открыты) и добавь ссылку.

Если всё равно не работает, просто напиши название песни текстом.

## 🛠 Если что-то не работает

| Проблема | Что делать |
|---|---|
| «Soundpad не найден» | Запусти Soundpad. Проверь, что у тебя не демо-версия |
| Ошибка при скачивании с YouTube | Перезапусти программу. Она сама обновляет скачивалку при запуске, свежая версия подхватится со следующего раза |
| Антивирус удалил exe | Добавь файл в исключения. Такое бывает с программами без платной подписи |
| Слишком тихо или громко | Ползунок громкости в Soundpad |
| Друзья не слышат | В Discord / игре должен быть выбран микрофон, к которому подключён Soundpad (см. настройки Soundpad) |
| Не качается из VK | Смотри «Как включить музыку из VK» выше, или напиши название текстом |

Настройки и скачанные треки хранятся в папке `%APPDATA%\SoundpadMusic`. Если она занимает много места, нажми в программе **«Очистить кэш»**.

---

## ❓ Как это работает внутри

Soundpad не умеет играть «прямой эфир», только файлы. Поэтому программа:

1. Находит трек по ссылке или названию.
2. Скачивает его и делает из него mp3.
3. Добавляет файл в Soundpad и командует «играй в микрофон».
4. Когда трек закончился, включает следующий из очереди.

Пока играет один трек, следующий уже скачивается, так что пауз почти нет. Уже скачанные треки второй раз запускаются мгновенно.

<details>
<summary>Для разработчиков</summary>

Запуск из исходников без exe (нужен Python 3.9+): `run.bat`, он сам создаст `.venv` и поставит зависимости.

exe собирается автоматически на GitHub (`.github/workflows/build.yml`) при каждом изменении в `main` и выкладывается в Releases. Сборка вручную:

```bat
pip install pyinstaller "yt-dlp[default]" imageio-ffmpeg
pip download yt-dlp --no-deps -d build_wheels
pyinstaller -y SoundpadMusic.spec
```

yt-dlp лежит внутри exe отдельным wheel-файлом. Программа сама скачивает его свежие версии с PyPI (со сверкой sha256) в `%APPDATA%\SoundpadMusic\lib`, поэтому exe не надо пересобирать каждый раз, когда YouTube что-то ломает. Вручную: `SoundpadMusic.exe --update`.

Запуск из консоли без окна:

```bat
python -m soundpad_music "https://youtu.be/..." "кино звезда по имени солнце"
```

Флаги: `--no-speakers`, `--no-normalize`, `--keep` (не удалять из списка Soundpad), `--cookies BROWSER`.

Тесты:

```bash
pip install -r requirements.txt
python -m unittest discover -s tests
```

Структура:
- `soundpad_music/soundpad.py`: управление Soundpad через named pipe `\\.\pipe\sp_remote_control`.
- `soundpad_music/sources.py`: разбор ссылок, Яндекс Музыка, скачивание (yt-dlp) и конвертация (ffmpeg).
- `soundpad_music/player.py`: очередь и предзагрузка.
- `soundpad_music/gui.py`: окно (tkinter).
- `soundpad_music/ytdlp_loader.py`: самообновление yt-dlp в exe.
</details>
